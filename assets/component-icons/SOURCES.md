# Component icon sources

The application embeds these fixed assets. It does not fetch icons at runtime.

- `yt-dlp.ico`: official yt-dlp repository, `devscripts/logo.ico`  
  <https://github.com/yt-dlp/yt-dlp/blob/master/devscripts/logo.ico>
- `gallery-dl.png`: official gdl-org GitHub organization avatar  
  <https://github.com/gdl-org.png>
- `ffmpeg.ico`: official FFmpeg website favicon  
  <https://ffmpeg.org/favicon.ico>
- `deno.svg`: official Deno website logo  
  <https://deno.com/logo.svg>
- `aria2.png`: official aria2 website favicon  
  <https://aria2.github.io/favicon.png>

The application icon is loaded from the existing `assets/logo.ico`.
